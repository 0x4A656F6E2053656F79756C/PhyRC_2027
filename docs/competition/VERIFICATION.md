# 설치·수집 검증 범위 — 2026-09-14

GitHub의 대회용 소스를 별도 폴더에 새로 복제해 확인했습니다.
검증한 실행 코드와 검사 수정은 현재 `main`에 통합되어 있습니다.
기존 개발 환경의 실행 폴더·다운로드 자산·시뮬레이터 캐시·저장 데이터를 복사하지 않았습니다.
**같은 PC에서 새 프로젝트 설치를 확인한 결과이며, 다른 PC나 새로 설치한 운영체제에서의 검증은 아닙니다.**

## 확인한 환경과 방법

- Ubuntu Desktop 22.04.5, X11 데스크톱, Intel Core i7-11700F, RAM 64GB.
- NVIDIA RTX 5080 16GB, 드라이버 580.178.04, Docker 29.1.3.
- 저장소가 지정한 Isaac Sim 6.0.1 이미지 사용. 프로젝트 Docker 빌드 단계는 캐시 없이 다시 실행했습니다.
- NVIDIA 기본 이미지 자체는 호스트에 있던 이미지를 사용했습니다. 운영체제·드라이버·Docker를 새로 설치하는 과정은 이번에 반복하지 않았습니다.

## 확인 결과

| 확인 항목 | 결과 |
|---|---|
| GitHub 소스만으로 환경 준비 | 통과. 필수 자산 8개 검증, 추가 자산 새로 다운로드, 실행 장면 생성 |
| 실행 코드 배치 | 통과. GitHub에서 받은 Python 소스 43개와 생성된 실행 코드 일치 |
| 실제 시뮬레이션 기본 검사 | 통과. 두 로봇 움직임, 그리퍼 개폐, 장면 상태 저장·불러오기 |
| 상태 불러오기 정확성 | 검사한 옷 정점 위치의 최대 오차 0m |
| GUI 키보드 조종과 ESC 종료 | 통과. 리프트 상승·팔 신장 명령 및 실제 관절 움직임 확인 |
| 학습 파일 자동 생성 | 통과. ESC 후 별도 변환 명령 없이 `READY`, `complete=true` 확인 |
| 수집 구간과 원본 기록 | 1개 에피소드, 9개 학습 구간(0.45 시뮬레이션초), 물리 tick 108개 누락 없음 |
| 5개 카메라 | RGB·depth·깊이 유효 마스크가 모두 저장되며 형식과 유효 값 검사 통과 |
| 데이터 동기화 | 관측·액션·제어 목표·카메라 자세를 원본과 대조. 카메라/화면 시각 일치 및 다음 관측 연결 검사 통과 |
| 버튼 없는 자동 평가 | `--evaluate 1`로 시작·저장 확인. 이번 짧은 무접촉 시도는 0점 결과로 저장 |

`./run.sh smoke`에 남아 있던 과거 환경 기준을 현재 배포 환경에 맞게 수정한 뒤 통과했습니다.
검사를 통과시키기 위해 로봇·마네킹·옷의 설정을 바꾸지는 않았습니다.
빈 캐시로 실행한 기본 검사는 약 6분이 걸렸습니다. 첫 실행에서는 장면 준비 뒤에도 추가 시간이 필요할 수 있습니다.

## 참가팀이 직접 확인할 순서

[설치 가이드](SETUP.md)에 따라 준비한 뒤 다음 명령을 순서대로 사용하세요.

```bash
./run.sh smoke
./run.sh gui --training-record 1 --evaluate 1
```

`PHYRC-SMOKE-PASS`를 확인하고 GUI를 실행합니다. 3D 장면 영역을 클릭해 짧게 조종한 뒤 ESC로 종료합니다.
**창이 닫힌 뒤에도 터미널을 유지하고 `[Dataset export] READY`를 기다리세요.**
[데이터 가이드](DATA.md#변환-재시도와-검사)의 검사 명령으로 자신의 학습 파일을 확인할 수 있습니다.

이번 검증은 설치·조종·저장 경로를 확인하는 짧은 기능 검사입니다.
완전 착의에 성공하는 정책의 학습이나 장시간 수집, 모든 GPU·드라이버·운영체제 조합을 보장하는 결과는 아닙니다.

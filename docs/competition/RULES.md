# 참가자 정책의 허용 정보·행동

정책 학습과 실행에는 [데이터 가이드](DATA.md)의 공개 observation과
[`config/policy_interface.json`](../../config/policy_interface.json)의 `(2,9)` action만 사용합니다.
본 규칙은 학습 데이터 생성, 학습, 추론에 모두 적용합니다.

## 허용

- 지정된 외부 카메라1개와 두 로봇의 손목·상단 카메라4개: RGB, depth, depth_valid.
- 관절 위치·속도, **로봇 자신의** 베이스 자세·속도, base 기준 그리퍼/손끝 상태, 공개 제어 목표/개폐 의도, 이전 action과 simulation_time_s.
- 명세를 해석하는 정적 카메라 보정, 관절 이름·단위, 공개 action 스케일.
- 허용 관측으로부터 물체/의복의 위치·특징을 **추정**하는 모델과 제어기.
- 사람이 teleop으로 생성한 공개 관측/action 시연을 사용한 학습.
- 점수·성공 라벨을 이용한 시연 선별 및 결과 분석. 해당 라벨은 정책 입력이나 행동 정답을 만드는 용도로 사용할 수 없습니다.

로봇 베이스의 월드 pose는 이 트랙에서 허용된 localization입니다. 이것을 사용하는 것 자체는 위반이 아닙니다.
마네킹·옷·의자의 정답 pose나 기록된 상태를 직접 덮어써 행동을 재현하는 것과 구분합니다.

## 금지

1. 옷 정점/입자 좌표·속도, 옷/마네킹/의자의 정확한 위치, 정답 segmentation,
   충돌 메시, 내부 파지 앵커/성공 상태, 평가기의 기하 판정값을 정책에 제공하는 행위.
2. 이러한 내부 정보로 목표점·행동 정답·자동 시연을 만들거나 교사 정책을 학습하고 증류하여 우회하는 행위.
3. raw archive의 로봇·옷 상태 궤적을 정답처럼 재생하거나 USD/시뮬레이터 상태를 직접 설정하는 행위.
   정책은 매20Hz에 허용 관측을 받아 명세의 action을 출력해야 합니다.
4. 감사 파일, 평가 JSON, 자유롭게 이동한 teleop viewport, episode spawn seed,
   물체 위치를 드러내는 동적 카메라 월드 행렬을 학습·추론 입력으로 사용하는 행위.
5. 로봇/그리퍼/옷/마네킹의 물리·형상·구동 제한·초기화 규칙이나 평가 함수를 바꾸어 제출 성능을 높이는 행위.

정책이 액션을 내보내도록 제공한 adapter 외 경로로 장면을 조작하지 마세요.
저장소의 연구·디버그 스크립트 중 내부 정답 정보에 접근하는 코드는 참가자용 학습 baseline으로 허용되지 않습니다.

## 검증과 제출 준비

**주최 측이 자체 구축·운영하는 검증 프로세스에서 금지 정보 사용 또는 환경 우회가 확인된 제출물은 심사에서 제외합니다.**
학습 코드, 데이터 출처·생성 방법, 체크포인트, 의존성, 실행 방법 및 로그를 제시할 수 있어야 합니다.
주최 측은 제출 자료를 검토하고 별도 초기 상태에서 재평가할 수 있습니다. 단순히 점수가 높다는 이유만으로 위반을 판정하지 않습니다.

공개 로컬 실행기의 스키마 검사를 통과했다는 사실만으로 규정 준수가 인증되는 것은 아닙니다.
최종 판정은 주최 측 검증을 따릅니다. 로컬 연습용 seed와 기록은 최종 심사 데이터가 아닙니다.
제출처·일정·최종 실행 제한은 대회 공지를 따릅니다.
